# Table Column Boundary Hover Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the blue column-boundary line on pointer hover while preserving an active resize indication.

**Architecture:** Split the combined `.table-column-drag-handle:hover, .table-column-drag-handle:active` rule into separate states. The hover state remains transparent; the active state retains the existing blue background.

**Tech Stack:** CSS, Node.js `node:assert`

## Global Constraints

- Preserve the column-resize hit area and `col-resize` cursor.
- Preserve the active drag background.
- Do not change row controls, insertion controls, or selected-line highlighting.
