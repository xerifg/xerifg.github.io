# Mermaid 流程图可视化编辑设计

## 目标

在文档编辑器的加号插入浮窗中提供 Mermaid 流程图块。用户可以像在飞书文档中一样插入图表，在画布上直接修改节点和连线；文档同时保留可编辑、可迁移的 Mermaid 源码。

首版支持 `flowchart` / `graph`。时序图、甘特图等其他 Mermaid 图表不进入可视化画布，仍可由源码方式扩展。

## 体验

- “+”浮窗的“插入”分组新增“Mermaid 流程图”。
- 插入操作创建一个带示例流程的原子块，块后追加空段落并将光标移入该段落。
- 非编辑状态显示 Mermaid SVG 预览。选中块后显示轻量的“编辑图表”和“删除”操作。
- “编辑图表”进入画布：可拖动节点、双击节点改文字、从节点的连接柄拉出箭头连线、选中后删除节点或连线。
- 源码面板默认折叠。展开后可修改 Mermaid；可解析的源码同步更新画布，不能解析时保留原始源码和当前可用画布，并显示错误。
- 退出编辑态会保存画布、节点位置和 Mermaid 源码；阅读态只渲染 SVG。

## 数据模型与同步

`mermaidDiagram` 为 Tiptap block atom，保存下列属性：

- `code`：标准 Mermaid 流程图源码，作为可移植的规范表示。
- `graph`：画布所需的 JSON（节点、连线、标签、形状和方向）。
- `positions`：以节点 id 为键的画布坐标，保证重新打开的布局稳定。
- `error`：最近一次源码解析失败的提示；不会替换最后一个有效的 `graph`。

画布操作先修改图模型，再生成 `code` 和 `positions`。源码操作先解析到临时模型；仅解析成功时同时更新 `graph`、`positions` 和预览，失败时只写入 `code` 与 `error`。渲染 SVG 使用 Mermaid 官方运行时，并关闭图内 HTML。

初版的图模型支持圆角矩形、矩形和菱形；支持有向边、边标签和上、下、左、右的自动布局。任意暂不支持的 Mermaid 语法在源码中保持原样，但不会承诺可视化画布可编辑。

## 组件边界

- `MermaidDiagram`：Tiptap 节点、HTML 序列化和预览壳层。
- `MermaidDiagramView`：编辑/阅读状态、错误提示和工具栏。
- `MermaidFlowCanvas`：节点、连接柄、选择状态和指针交互；不直接操作编辑器。
- 图模型辅助函数：解析 Mermaid、生成 Mermaid、应用画布变更和布局，放在独立模块中并以单元测试覆盖。

## 错误处理和安全

- Mermaid 运行时仅接受图模型生成或用户提供的流程图源码，并启用严格安全级别，不执行图内 HTML。
- 渲染错误局限在当前块，显示中文错误信息，不影响文档其他内容或保存。
- 删除节点同时删除关联连线；删除连线和重命名节点立即同步源码。

## 测试

- 插入菜单包含 Mermaid 流程图命令，命令插入节点并保留后续可编辑段落。
- 图模型可在 Mermaid 源码和画布 JSON 之间稳定转换，涵盖节点、箭头、标签与形状。
- 节点移动、节点改名、添加和删除连线都会更新源码和位置数据。
- 无效 Mermaid 源码保留输入和上一个有效图模型，并产生错误状态。
- 节点 HTML 的序列化/解析可使保存后的文档在阅读态再次展示同一图表。
