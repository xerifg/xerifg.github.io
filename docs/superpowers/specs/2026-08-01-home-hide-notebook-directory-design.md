# 首页隐藏知识库目录设计

## 目标

用户从主导航进入“首页”时，不显示知识库笔记目录；进入“笔记”时，目录照常显示并保持现有功能。

## 方案选择

采用在应用壳层按当前 `state.view` 条件渲染知识库目录的最小改动方案。

- 方案 A（采用）：仅在 `library` 视图渲染 `ContextSidebar` 及其窄屏目录切换按钮。改动集中，不影响目录的数据、交互或其他视图的专用侧栏。
- 方案 B：通过 CSS 在首页隐藏目录。会保留无用的可访问性节点和窄屏交互，不采用。
- 方案 C：重构为按视图注册侧栏。对单一显示规则来说范围过大，不采用。

## 交互与状态

- 点击“首页”后，主功能轨与首页内容照常显示，知识库目录不渲染。
- 点击“笔记”后，知识库目录与已有的搜索、树形目录、新建及菜单操作照常可用。
- “标签”和“设置”保持当前的各自侧栏逻辑，不受影响。
- 小屏幕下，目录抽屉开关也只在“笔记”视图提供，避免首页出现孤立的目录入口。

## 实现边界

- 修改应用壳层的条件渲染，不更改目录数据、持久化规则、导航状态模型或 CSS 布局。
- 为壳层源码测试增加断言，覆盖首页不渲染目录、笔记页仍渲染目录的条件。

## 验证

1. 自动化测试确认壳层的目录与窄屏目录开关只绑定 `library` 视图。
2. 运行现有测试套件，确保导航与目录相关测试继续通过。
