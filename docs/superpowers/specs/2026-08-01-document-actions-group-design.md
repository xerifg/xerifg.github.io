# 文档页右上角操作组（方案 A）

## 目标

让文档页右上角的操作层级与轻盈、半透明的知识库界面一致。阅读/编辑与更多操作属于次要控制；发布是唯一的主要动作。

## 交互与布局

- 将现有「编辑」切换按钮和「更多」按钮包入同一个浅色分组容器。
- 分组容器为圆角胶囊，包含：带铅笔图标的「编辑」按钮、细竖分隔线、仅图标的更多按钮。
- 更多按钮继续打开现有文档操作菜单；键盘、焦点和菜单行为不变。
- 「发布」保留在分组右侧，间距 10px，添加向上箭头图标；发布中状态仍显示「发表中」。
- 保持既有动作语义和后端处理不变；本次只调整顶部工具栏的呈现。

## 视觉规则

- 所有按钮高度统一为 34px，圆角 10px。
- 次要分组使用低对比度半透明灰白背景与极细边框，不用实心深灰底。
- 编辑按钮在编辑状态用柔和蓝色的浅色态表达状态，不与发布按钮竞争。
- 发布按钮使用现有品牌蓝色实底与白色图标文字，是视觉锚点；悬停、禁用和焦点状态沿用当前可访问性标准。
- 小屏幕仍允许工具栏自然排列，不遮挡文档标题或菜单。

## 验收

- 三个操作在视觉上呈现为「次要分组 + 主操作」，不再像三个并列按钮。
- 编辑模式切换、更多菜单、发布和发布中禁用状态均保持原有功能。
- 不影响键盘操作、焦点可见性及现有响应式布局。
