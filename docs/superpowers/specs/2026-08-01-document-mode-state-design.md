# 文档模式按钮状态设计

## 目标

让文档顶部的模式按钮明确表示当前模式，而不是点击后将切换到的模式；新打开的文档仍默认进入阅读模式。

## 范围与交互

- `state.mode === "read"` 时，按钮显示书本图标和“阅读”。
- `state.mode === "edit"` 时，按钮显示笔图标和“编辑”。
- 仅 `state.mode === "edit"` 时使用现有高亮状态样式；阅读模式保持普通样式。
- 点击按钮仍只在阅读与编辑间切换；从阅读切换编辑时，继续沿用既有编辑权限验证。
- 种子状态、选择文档和新建文档的默认模式保持为阅读模式，不改变设置中的默认模式偏好。

## 实现

在 `renderDocumentTopbar` 中，根据 `state.mode` 选择图标、文案和 `.active` 类。按钮的 `aria-pressed` 表示它是否处于编辑模式，保持现有无障碍语义。

## 验证

新增静态 UI 回归测试，断言阅读模式分支使用 `read` 图标和“阅读”，编辑模式分支使用 `edit` 图标和“编辑”，且默认种子模式为 `read`。运行全部 Node 测试，确保不影响既有功能。
